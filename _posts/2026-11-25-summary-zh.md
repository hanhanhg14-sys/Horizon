### [OpenAI 预印本称矩阵乘法指数为Θ\(n^2.25\)](https://github.com/openai/math/blob/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/paper.pdf) ⭐️ 10.0/10

OpenAI 的预印本声称证明矩阵乘法指数恰为 9/4（即 Θ\(n^2.25\)），对任意域成立，并给出下界 Ω\(n^2.25\)；此前已知上界为 2.25。同一论文还宣称给出强多项式线性规划（Smale 第九问题）、均值支付博弈和奇偶博弈的多项式时间算法。这些结果仍属预印本声明，尚未经独立验证。

hackernews · E-Reverance · 11月25日 01:19 · [社区讨论](https://news.ycombinator.com/item?id=50637220)

**「背景」** 矩阵乘法指数 ω 是衡量最优矩阵乘法算法复杂度的核心参数，定义为使 n×n 矩阵乘法可在 O\(n^ω\) 时间内完成的最小实数；长期以来许多研究人员猜想 ω=2。过去若干年只有上界被不断改进，但精确值始终未知，这一新预印本声称给出下界并确定精确值为 9/4。

**「影响」** 若该预印本被验证，矩阵乘法下界 Ω\(n^2.25\) 将推翻 ω=2 的猜想，并意味着在渐进意义上继续寻找更快通用矩阵乘法算法的空间被封闭；同时强多项式线性规划的算法声明若成立，将改变线性规划求解器的理论保证。

**「社区讨论」** 评论区指出原文标题应为 Θ\(n^2.25\) 而非 O\(n^2.25\)：该结果给出的是下界 Ω\(n^2.25\)，而 2.25 的上界此前已知。另有评论提醒该工作来自未公开模型且未披露方法，存在透明度担忧。

### [CVE-2022-0847 Dirty Pipe Linux 内核本地提权漏洞 PoC 公开](https://cve.now/CVE-2022-0847) ⭐️ 9.0/10

CVE-2022-0847（Dirty Pipe）漏洞的利用代码已在 GitHub 公开。该 Linux 内核缺陷源于管道缓冲区设置未初始化，低权限本地攻击者可通过页缓存覆盖只读文件内容，进而向 root 进程注入代码并提升至 root 权限。该漏洞已被列入 CISA 已知被利用漏洞（KEV）目录，表明已有实际攻击发生。

rss · cve.now 新收录的 CISA KEV · 11月25日 02:01

**「背景」** Linux 内核的管道缓冲区通过 flags 标志控制对页缓存中文件页的写入权限。该漏洞中，flags 未正确初始化会使只读文件页被标记为可写，攻击者因此能绕过只读保护和权限检查，通过向管道写入数据来篡改文件内容，并借由向 root 进程注入代码实现提权。

**「影响」** 运行受影响 Linux 内核的系统面临本地提权风险：任何低权限账户都可能利用公开 PoC 获取 root 权限。系统管理员应立即确认内核版本并应用补丁，尤其是需遵守 CISA KEV 修复期限的机构。

### [Check Point 安全管理服务器遭主动入侵，攻击者伪造管理员 Cookie](https://www.greynoise.io/blog/check-point-security-management-servers-intrusion-campaign) ⭐️ 8.0/10

GreyNoise 报告称，Check Point 安全管理服务器正成为一起主动入侵活动的目标。攻击者利用 HFS 的 loginSrp1 登录端点：每次 POST 会返回一个带 “sid” 值的签名会话 Cookie，该值取自 JavaScript 的 Math.random\(\)。通过连续登录收集足够输出，攻击者可重建 Node.js V8 PRNG 的内部状态，恢复 HFS 会话 Cookie 签名密钥，并据此伪造管理员会话 Cookie。现有材料没有完整说明初始入侵途径；有评论推测 CVE-2026-16232 可能是初始向量，但尚不清楚是否要求相关服务器暴露在公网。

hackernews · louiereederson · 11月24日 16:32 · [社区讨论](https://news.ycombinator.com/item?id=50630594)

**「背景：HFS 会话签名与可预测的 PRNG」** Check Point 安全管理服务器通过 HFS 组件提供基于 SRP 的登录接口，登录成功后签发包含 sid 值的签名会话 cookie。该 sid 由 Node.js 的 Math.random\(\) 生成，而 Math.random\(\) 不是加密安全随机数生成器，其输出序列可用于重构 V8 引擎的 PRNG 内部状态。攻击者通过连续多次登录收集输出，便可恢复 cookie 签名密钥并伪造管理员会话。

**「影响」** 使用 Check Point 安全管理服务器的组织面临未经授权的管理员会话风险。建议尽快确认 HFS 服务是否可从公网访问，并检查 loginSrp1 端点是否存在异常的多次登录记录。

**「社区讨论」** 评论区有人质疑初始访问途径：不清楚是否所有受影响组织都将 Check Point Security Management Server 暴露在公网，并猜测 CVE-2026-16232 可能是初入点（omh）。另有观点认为应从随机数生成器本身修复，而不是责怪使用不当的应用（20after4）。
